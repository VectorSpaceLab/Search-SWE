I need to select promising compounds from a large combinatorial molecular library for a later, expensive validation step. The conditions will change between requests: each specifies a docking target and molecular-property limits, and I can validate at most 10,000 candidates. Please build a reusable search system that returns the candidates most likely to include the truly best feasible compounds, while returning each complete candidate set within two seconds.
