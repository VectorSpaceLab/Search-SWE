Let `N = 100 * test_query_count * 10` be the total number of true-neighbor positions, `C = N * (1 - R)` the missed-hit count, and `Cbase = N * (1 - Rbase)` the fixed baseline missed-hit count. Counts are integers (the evaluator rounds the reconstructed counts only to remove floating-point averaging noise), and Cbase must be at least one; otherwise the reference is a setup error. The added one handles zero errors at the actual one-hit resolution; there is no fitted exponent or target model score. Matching or falling below baseline earns zero recall credit; zero missed hits earns full recall credit.
