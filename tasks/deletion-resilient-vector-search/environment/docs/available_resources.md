# Available resources

Use only the supplied local vectors, calibration data, public development deletion
order, frozen reference measurements, installed libraries and compiler/runtime.
No network, additional datasets, GPU, external embeddings, search services,
rerankers or model APIs are available to the submission. No submission API keys
are injected. The coding agent's provider connection is a harness exception only.

The public exact/HNSW reference programs are optional tools. No algorithm or
training procedure is mandatory beyond a genuine graph index and the task's
interface/resource requirements. Hidden inputs, future deletion IDs, answers,
grader state and previous evaluation outputs are not permitted resources.
