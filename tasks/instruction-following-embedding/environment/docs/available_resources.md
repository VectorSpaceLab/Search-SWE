# Available Resources

Network access is disabled. Use only the supplied E5-large-v2 model, task data and installed Python packages and system tools. Do not download packages, checkpoints or datasets, or use external LLM, embedding or reranking APIs. No task API credentials are provided.

The model is under `/task/models/e5-large-v2`; training data is `/task/data/train.jsonl`, validation data is `/task/data/validation/dev-groups.json`, and passages are under `/task/corpus`. Training and validation uses must follow the restrictions in the task instruction.
