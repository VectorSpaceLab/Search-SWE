The quality goal is to put relevant code within the first five examples to inspect. For a hidden question, Accuracy@5 is one if at least one relevant code document appears among the first five reranked candidates and zero otherwise. Let B be the original reranker's mean Accuracy@5, S the submitted reranker's mean, and C the fraction of all hidden questions whose fixed RRF union contains at least one relevant document. C is the best Accuracy@5 attainable without changing those candidates. Reward is max(0, (S-B)/(C-B)), clamped to the range 0 to 1, when C>B; if C=B, including when the first stage has no hits, reward is zero because there is no improvement headroom. Copying or worsening the baseline yields zero, and reaching the attainable ceiling yields one when headroom exists. Questions with no relevant candidate stay in the denominators of B, S and C. All three values are recalculated from each evaluation's shared fixed candidates.
